# 🎨 PaletteSniper

**PaletteSniper** — легкое и быстрое приложение для захвата цветов с экрана.

## ✨ Основные возможности

- 🎯 **Мгновенный захват** — выбор любого пикселя на экране с помощью глобального хоткея.
- 📋 **Буфер обмена** — автоматическое копирование выбранного цвета.
- 🎨 **Форматы** — поддержка HEX, RGB и HSL.
- 🔍 **Умная лупа** — зум до 24× для точного выбора пикселя.
- 📜 **История** — сохранение последних использованных цветов.
- ⚖️ **Контрастность** — автоматический подбор цвета текста для фона.
- ⚙️ **Гибкие настройки** — хоткей, автозапуск, затемнение экрана.

## 📥 Установка

1. Перейдите в раздел [Releases](https://github.com/Lemon4ikBY/PaletteSniper/releases).
2. Скачайте файл `PaletteSniper-Setup.exe`.
3. Запустите установщик и следуйте инструкциям.

## 🛠 Сборка из исходного кода

**Требования:**

- Qt 6.8 или новее
- CMake 3.21 или новее
- C++17 совместимый компилятор (MinGW / MSVC)

**Команды для сборки:**

    git clone https://github.com/Lemon4ikBY/PaletteSniper.git
    cd PaletteSniper
    mkdir build && cd build
    cmake ..
    cmake --build . --config Release
